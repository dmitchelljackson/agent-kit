title: A bookmark is a reminder, not a rule
---

A bookmark is a skill generated from a page's `bookmark:` field. Its description says *when* to use it;
its body only says "run `akit read <page>`". It holds no rules; the page does.
akit writes the skill to `.agents/skills/` and mirrors it into each configured agent's skills folder.
