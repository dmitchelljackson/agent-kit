title: When to create a bookmark
---

Create one only when both hold:

1. a page must be read at a specific, recognizable moment, and
2. skipping it caused a mistake, or plausibly would.

Don't bookmark general background; the index covers that. If an existing bookmark fires at the same
moment, add a link on that page instead of creating a new bookmark.
Why: every bookmark's description sits in every session's context; too many and they stop being noticed.
